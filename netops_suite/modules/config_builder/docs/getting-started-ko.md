# CLI 설정 생성 사용자 가이드

NetOps Suite 통합 앱의 최신 사용법은 중앙 사용자 가이드에서 관리합니다.

- 앱 안에서 `CLI 설정 생성` 화면을 연 뒤 `F1`을 누르세요.
- 저장소에서는 [CLI 설정 생성 가이드](../../../../docs/user/ko/config-builder.md)를 확인하세요.
- 전체 편집기의 `튜토리얼` 버튼을 누르면 프로파일 작성부터 첫 CLI 복사까지 안전한 실습을 진행할 수 있습니다.

이 호환 문서는 과거 독립 실행형 Switch Config Builder 경로를 안내하지 않습니다.
실행은 저장소 루트의 `main.py` 또는 공식 NetOps Suite 설치본을 사용하세요.
