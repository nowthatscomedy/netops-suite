# 장비 설정 생성 사용자 가이드

NetOps Suite 통합 앱의 최신 사용법은 중앙 사용자 가이드에서 관리합니다.

- 앱 안에서 `설정 명령 만들기` 화면을 연 뒤 `F1`을 누르세요.
- 저장소에서는 [설정 명령 만들기 가이드](../../../../docs/user/ko/config-builder.md)를 확인하세요.
- 프로파일을 선택해 샘플 또는 장비 변수 파일로 시작하고, 입력한 값의 CLI를 확인·복사·저장합니다.

이 호환 문서는 과거 독립 실행형 Switch Config Builder 경로를 안내하지 않습니다.
실행은 저장소 루트의 `main.py` 또는 공식 NetOps Suite 설치본을 사용하세요.
