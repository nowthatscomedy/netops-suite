# 장비 점검 및 백업 가이드

## 목적 {#inspector}

Excel 장비 목록을 검증한 뒤 SSH 또는 Telnet으로 여러 장비의 점검 명령, 설정 백업, 점검+백업 또는 사용자 명령을 실행합니다. 장비별 결과 Excel, 백업, 세션 로그와 raw command output을 남겨 반복 작업을 표준화합니다.

![장비 점검 및 백업 화면](assets/generated/inspector-overview.png)

## 사전 준비 및 권한

- 장비 접속과 명령 실행에 대한 조직 승인이 필요합니다.
- 대상 장비의 제조사·모델·OS·버전에 맞는 프로파일을 `프로파일 관리` 또는 `지원 보기`에서 확인합니다.
- 대상 목록은 `.xlsx`, `.xls`, `.xlsm` Excel 파일이어야 합니다. 암호화 파일이면 화면의 `Excel 암호`에만 암호를 입력합니다.
- 필수 열은 `ip`, `vendor`, `os`, `connection_type`, `port`, `password`이고 선택 열은 `username`, `enable_password`입니다.
- 사용자 명령 파일은 `.txt`, `.xlsx`, `.xls`, `.xlsm`을 지원합니다.
- 장비 세션 수 제한과 네트워크 부하를 고려해 동시 작업 수를 보수적으로 정합니다.

## 입력 및 선택 사항

- 실행 모드:
  - `점검`: 프로파일의 읽기 중심 점검 명령 실행
  - `백업`: 프로파일의 백업 명령 실행
  - `점검+백업`: 두 작업을 함께 실행
  - `사용자 명령`: 사용자가 제공한 명령을 장비별로 실행
- `동시 작업 수`: 1~128, 기본 10
- `Timeout(초)`: 1~300, 기본 10
- `재시도`: 0~20, 기본 3
- `결과 파일명`: 기본 `inspection_results.xlsx`; 모드에 따라 실제 결과 이름이 조정될 수 있습니다.
- 사용자 명령 형식은 장비 Excel 열을 `{{ variable_name }}`로 참조합니다.

예제 장비 행은 문서·실습 전용 값을 사용합니다.

| ip | vendor | os | connection_type | port | username | password | new_hostname |
| --- | --- | --- | --- | ---: | --- | --- | --- |
| `192.0.2.10` | `cisco` | `ios` | `ssh` | 22 | `example-operator` | `CHANGE_ME_PASSWORD` | `LAB-SW-01` |
| `192.0.2.11` | `cisco` | `ios` | `ssh` | 22 | `example-operator` | `CHANGE_ME_PASSWORD` | `LAB-SW-02` |

## 사용 방법

### 프로파일 확인

1. `지원 보기`를 눌러 제조사, OS, Netmiko `device_type`, 명령 수, 백업 명령, 파싱 규칙과 출력 열을 확인합니다.
2. 맞는 조합이 없으면 `프로파일 관리`에서 기존 프로파일을 참고해 사용자 프로파일을 작성합니다.
3. 번들 프로파일과 `reference` 프로파일은 구조 참고용입니다. 실제 장비 출력으로 파싱 결과를 검증한 뒤 사용합니다.

### 안전한 사전 검증

1. 처음이면 `샘플 생성`을 눌러 예약 주소와 자리표시자 자격 증명이 든 Excel을 만듭니다.
2. 실환경 실행 전에는 샘플의 구조만 참고해 별도의 보안 승인된 장비 목록을 만듭니다.
3. `장비 목록 Excel > 선택`으로 파일을 선택합니다.
4. 암호화된 Excel인 경우에만 `Excel 암호`를 입력합니다.
5. 실행 모드와 필요 시 사용자 명령 파일을 선택합니다.
6. `먼저 검증`을 눌러 필수 열, 제조사/OS 조합과 사용자 명령 변수 전체를 확인합니다. 검증은 장비에 접속하지 않습니다.

### 점검·백업 실행

1. 검증 성공 후 동시 작업 수, Timeout, 재시도와 결과 파일명을 확인합니다.
2. `실행`을 누릅니다.
3. 확인 창에서 대상 수, SSH/Telnet 접속, 동시성, 세션 잠금·부하 가능성, 산출물 위치를 읽습니다.
4. 승인하면 진행 상태와 장비별 메시지를 확인합니다.
5. 긴급 중단이 필요하면 `중지`를 누릅니다. 이미 장비에서 실행 중인 명령은 즉시 취소되지 않을 수 있으므로 종료 상태까지 기다립니다.
6. 완료 후 `결과 Excel 열기`, `폴더 열기`, `로그 보기`로 결과를 검토합니다.

### 사용자 명령 변수

장비 목록에 `interface`, `vlan_id`, `new_hostname` 같은 열이 있다면 다음처럼 사용할 수 있습니다.

```text
show interface {{ interface }}
show vlan {{ vlan_id }}
hostname {{ new_hostname }}
```

- 같은 명령 패턴을 사용해도 각 장비 행의 값으로 따로 치환됩니다. 화면에는 Excel의 특정 행만 선택하는 기능이 없으므로 대상은 선택한 Excel의 전체 장비입니다.
- 변수명은 영문 소문자, 숫자, 밑줄만 사용하고 숫자로 시작하지 않습니다.
- 필터와 조건문은 지원하지 않습니다.
- 참조 열이나 값이 하나라도 누락되면 장비에 연결하기 전에 전체 실행이 차단됩니다.
- `password`, `enable_password`는 명령 변수로 사용할 수 없습니다.
- Excel에서 치환되는 값에는 제어 문자와 명령 구분·리디렉션 문자 `;`, `&`, `|`, `<`, `>`를 사용할 수 없습니다. 이런 값이 하나라도 있으면 장비에 연결하거나 실행 산출물을 만들기 전에 전체 실행이 차단됩니다.
- 운영자가 명령 패턴에 직접 작성한 문자는 기존 방식으로 처리되지만, Excel 값으로 명령 문법을 추가할 수는 없습니다.
- 실제 치환 명령은 결과·세션 로그·raw output에 남을 수 있으므로 비밀값을 변수에 넣지 않습니다.
- `먼저 검증`은 파일 구조와 변수 치환 가능 여부를 확인하며, 명령이 해당 장비에서 안전하게 동작하는지 보장하는 dry-run은 아닙니다.

## 성공 확인

- `먼저 검증` 후 `검증 완료: 장비 n대`가 표시됩니다.
- 사용자 명령이면 명령 수와 사용 변수 목록이 검증 요약에 함께 표시됩니다.
- 실행 완료 후 모드, 전체 장비 수, 결과 수와 산출물 경로가 표시됩니다.
- 결과 Excel의 장비 행 수와 대상 목록을 비교하고, 실패·재시도·파싱 오류 열을 확인합니다.
- 백업 모드에서는 기대한 장비별 백업 파일이 생성됐고 내용이 완전한지 확인합니다.
- 일부 장비만 성공해도 전체 작업은 결과 파일을 만들 수 있으므로 성공 메시지만 보지 말고 각 행을 검토합니다.

## 결과 및 저장 위치

- 점검 실행 작업 폴더는 기본적으로 `%LOCALAPPDATA%\NetOps Suite\inspector\runs`입니다.
- 결과 Excel, 설정 백업, 장비별 세션 로그와 사용자 명령 raw output이 실행별 하위 경로에 기록될 수 있습니다.
- `샘플 생성` 저장 창의 기본 제안 위치는 현재 결과/내보내기 폴더입니다.
- 사용자 프로파일, 사용자 규칙과 파서는 데이터 루트의 `inspector` 아래에 저장됩니다.
- `설정 > 저장 위치`에서 결과/내보내기 폴더를 바꿔도 inspector 실행 폴더는 데이터 루트 아래에 유지됩니다. 화면의 `폴더 열기`로 실제 경로를 확인하세요.

## 주의사항

- 장비 Excel은 비밀번호 열을 포함합니다. 파일 시스템 권한, 저장 장치 암호화, 보관 기간과 폐기 절차를 적용하세요.
- Telnet은 통신을 암호화하지 않습니다. 가능한 경우 SSH를 사용합니다.
- 기본 점검·백업 프로파일은 설정 변경을 의도하지 않지만, 사용자 프로파일의 명령 내용은 반드시 검토해야 합니다.
- 사용자 명령은 설정 저장·재부팅·삭제 등 되돌리기 어려운 작업을 포함할 수 있습니다. 읽기 전용 명령부터 별도 테스트 장비에서 검증하세요.
- 현재 사용자 명령 실행 경로는 조회 명령 중심입니다. `configure terminal`, 호스트네임 변경처럼 설정 모드나 프롬프트를 바꾸는 명령은 안전 실행이 검증된 기능으로 안내하지 않으며, 변경 전 백업과 승인된 별도 적용 절차를 사용합니다.
- 높은 동시 작업 수는 AAA, 장비 CPU, 세션 제한과 네트워크에 영향을 줄 수 있습니다.
- 결과·백업·로그·raw output에는 내부 주소, 구성, 계정명, 명령과 명령 출력이 포함될 수 있습니다.
- `중지`는 새 작업을 막고 종료를 요청하지만 이미 전달된 장비 명령을 되돌리지 않습니다.

## 문제 해결

- 검증이 실패하면 먼저 필수 열 철자와 빈 값을 확인한 뒤 `지원 보기`의 vendor/os 값과 정확히 맞춥니다.
- 암호화 Excel을 열지 못하면 파일 암호가 맞는지, 지원되는 Excel 형식인지 확인합니다.
- 모든 장비가 로그인 실패하면 연결 방식, 포트, 계정 정책, SSH 알고리즘 또는 Telnet 허용 여부를 확인합니다.
- 일부 장비만 실패하면 결과 Excel과 해당 장비 세션 로그를 비교합니다.
- 파싱 열이 비거나 어긋나면 장비 모델·OS 버전의 실제 출력과 프로파일 규칙을 대조합니다.
- 사용자 명령 검증 실패는 변수명, Excel 열, 모든 행의 값과 금지된 비밀번호 변수를 확인합니다. 오류에 제어 문자 또는 `; & | < >`가 표시되면 해당 Excel 셀을 일반 텍스트 값으로 고친 뒤 `먼저 검증`을 다시 누릅니다.
- 중지 후 화면이 즉시 끝나지 않으면 진행 중인 네트워크 호출이 Timeout 또는 안전한 종료 지점에 도달할 때까지 기다립니다.
