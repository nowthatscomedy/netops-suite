# NetOps Suite v1.6.0

`v1.6.0`은 압축을 풀어 쓰는 포터블 실행본(USB 포함)이 앱 안에서 바로 자기 폴더를 새 버전으로 바꾸도록 업데이트 방식을 고치고, 화면이 작을 때 가려지거나 비어 보이던 곳 세 군데를 정리한 기능 릴리스입니다.

## 한눈에 보기

- 포터블 실행본에서 `업데이트 확인`을 누르면 설치 프로그램 대신 포터블 zip을 받아 같은 폴더의 프로그램 파일을 바꾸고 다시 실행합니다.
- 포터블 업데이트는 `data` 폴더의 설정과 결과를 그대로 두고, 관리자 권한을 요구하지 않습니다.
- 교체 중 오류가 나면 이전 파일로 되돌리고 이전 버전을 다시 실행하며 이유를 알려 줍니다.
- 시작 준비 창, 파일 전송 옵션, ARP 스캔 화면이 작은 창에서도 잘리거나 빈칸 없이 보입니다.

## 이전 버전과 달라진 점

v1.5.0까지는 포터블 실행본에서 업데이트를 진행해도 설치 프로그램을 받아 실행했습니다. 그래서 USB에 담아 쓰는 경우 현재 PC의 Program Files에 설치판이 따로 생기고, USB 안의 프로그램과 `data` 폴더는 이전 버전 그대로 남았습니다. 이제 포터블 실행본은 `NetOpsSuite-portable-<버전>.zip`을 받아 실행 파일과 `_internal` 폴더만 새 버전으로 바꿉니다.

이 기능은 v1.6.0부터 들어 있으므로, v1.5.0 이하 포터블 실행본은 이번 한 번만 `NetOpsSuite-portable-1.6.0.zip`의 압축을 풀어 기존 폴더에 덮어써야 합니다. 그 뒤 업데이트부터는 앱 안에서 자동으로 교체됩니다.

## 새 기능

- 포터블 업데이트 자동 교체: `설정 > 프로그램 > 업데이트 확인`에서 새 버전을 받고 `포터블 업데이트 적용`을 확인하면, 앱이 종료된 뒤 새 버전이 프로그램 파일을 교체하고 같은 폴더에서 다시 실행됩니다. 다시 열린 앱의 설정 화면에 `포터블 폴더를 <버전> 버전으로 교체했습니다.`가 표시됩니다.

## 개선 및 수정

- 시작 준비 창이 단계 목록과 진행 로그를 모두 보이도록 높이를 맞추고, 얇은 진행 막대 위에 잘려 보이던 퍼센트 글자를 없앴습니다.
- 파일 전송의 접힌 옵션을 펼쳤을 때 항목 사이에 빈칸이 생기지 않도록 옵션 배치를 다시 채웁니다.
- ARP 스캔 화면은 창이 작으면 결과 표와 진행 로그를 자르는 대신 아래로 스크롤해서 볼 수 있습니다.
- 설치·설정·진단 도움말을 새 동작에 맞게 고쳤습니다.
- 앱에 포함된 인증서 묶음(`certifi`)을 보안 권고 GHSA-6q48-6c7w-9gw2가 반영된 2026.10.19로 올렸습니다.

## 설치 및 주의사항

- 지원 환경은 64비트 Windows 10 버전 1809(빌드 17763) 이상입니다.
- 설치 파일은 `NetOpsSuite-setup-1.6.0.exe`, 설치 없이 쓰는 압축 파일은 `NetOpsSuite-portable-1.6.0.zip`입니다.
- 기본 Program Files 설치 위에 실행하면 이전 실행 파일과 `_internal` 앱 번들이 새 버전으로 교체됩니다. 실행 중인 NetOps Suite를 먼저 종료하세요.
- 포터블 업데이트 중에는 창이 표시되지 않습니다. 앱이 다시 열릴 때까지 USB를 뽑거나 프로그램을 직접 실행하지 마세요.
- 저장된 프로파일 파일과 장비 목록 Excel 형식은 바뀌지 않았습니다.
- 코드 서명 인증서가 구성되지 않은 경우 명시적으로 승인된 무서명 릴리스로 게시되며, Windows에서 확인된 게시자 정보가 표시되지 않을 수 있습니다.

## 검증 및 무결성

- 가이드 생성·검증, 정적 검사, 의존성 감사, Python 컴파일과 전체 자동화 테스트를 릴리스 워크플로에서 수행합니다.
- 포터블 교체, `data` 폴더 보존, 실패 시 이전 버전 복구, 다운로드 후 변경된 zip 차단, 압축 파일 경로 탈출 차단을 자동화 테스트로 검사합니다.
- 설치 파일, 포터블 zip과 함께 `SHA256SUMS.txt` 및 CycloneDX 형식의 `python-dependencies.cdx.json`을 게시합니다. 실제 체크섬과 서명 상태는 게시된 자산과 워크플로 결과에서 확인하세요.
