# NetOps Suite v1.3.0

`v1.3.0`은 처음 쓰는 사람도 장비 점검 프로파일을 직접 만들 수 있도록 작성 흐름을 바꾼 기능 릴리스입니다. 장비 출력에서 값을 마우스로 고르면 추출 규칙이 자동으로 만들어지고, 장비로 시험하는 동안 CLI 세션을 실시간으로 볼 수 있습니다. 앱 전체에 필수 입력 칸 표시를 넣었고, 비밀번호 없이 바로 CLI가 열리는 장비의 Telnet 접속 문제를 고쳤습니다.

## 한눈에 보기

- 프로파일 만들기의 `5. Excel 컬럼`에서 출력의 값을 드래그하고 `선택한 값으로 컬럼 만들기`를 누르면 값을 다시 찾는 규칙이 자동으로 만들어집니다.
- 프로파일 만들기 탭에 1~6 번호를 붙이고 `다음` 버튼으로 순서대로 진행하게 했습니다.
- `장비로 시험`을 실행하는 동안 장비와 주고받는 CLI 화면이 `세션 화면 (실시간)`에 그대로 나옵니다.
- 앱 전체의 입력 칸에 필수 표시(`*`)를 붙이고, 비었거나 잘못된 칸은 빨간 테두리로 알려 줍니다.
- 연결 진단의 결과 표를 `크게 보기`로 작업 영역 전체에 펼쳐 볼 수 있습니다.

## 이전 버전과 달라진 점

v1.2.0까지는 Excel 컬럼을 만들 때 "몇 번째 줄 몇 번째 값", "특정 단어 뒤", 정규식 중 하나를 직접 고르고 숫자나 패턴을 입력해야 했습니다. 이번 버전은 출력에서 값을 고르면 값 앞의 글자(예: `Processor board ID`, `Version`)를 기준으로 규칙을 만들고, 그 규칙으로 같은 값이 실제로 나오는지 확인한 것만 제안합니다. 직접 설정은 `추출 규칙 직접 고치기` 안으로 옮겼습니다.

프로파일 만들기 탭 순서는 장비 정보 → 점검 명령 → 백업 명령 → 장비로 시험 → Excel 컬럼 → 확인·저장으로 바뀌었습니다.

AxGate·NexG·Ubiquoss의 Telnet 로그인은 `Username:`, `Password:` 프롬프트를 무조건 기다렸습니다. 그래서 비밀번호가 없어 바로 `#` 프롬프트가 나오는 장비는 40초가량 멈춘 뒤 계정과 비밀번호를 명령처럼 입력했습니다. 이제 장비가 실제로 보여 주는 프롬프트에만 답합니다.

연결 진단의 `보기`는 결과 표를 아래쪽 작은 창으로 따로 띄우던 방식에서, 작업 영역 전체에 펼치는 방식으로 바뀌었습니다.

## 새 기능

- 값 골라 컬럼 만들기: 여러 규칙이 가능하면 `찾는 방법`에서 바꿀 수 있습니다. 줄·값 위치로 찾는 방법에는 `(위치 기준)`이 붙어 다른 장비에서 틀릴 수 있음을 알려 줍니다.
- 실시간 세션 화면: 로그인 프롬프트, enable 단계, 명령 출력이 어디서 멈추는지 시험하는 동안 바로 볼 수 있습니다.
- 필수 입력 표시: 연결 진단, 파일 전송, 내 PC 네트워크, 장비 점검·백업, 설정 명령 만들기와 각종 프로파일 대화상자에 적용했습니다. 필수 칸이 비면 실행·저장·다음 단계가 막히고 채울 칸을 알려 줍니다.
- 결과 크게 보기: Ping·포트 확인 결과 아래 `크게 보기`나 `보기` 메뉴로 결과 표를 펼치고, `원래 화면으로`나 Esc로 돌아옵니다.

## 개선 및 수정

- 장비 목록 Excel의 `password` 칸을 비워 둘 수 있습니다. 숫자 비밀번호 열에 빈칸이 섞이면 `1234`가 `1234.0`으로 바뀌던 문제를 고쳤습니다.
- 왼쪽 메뉴 아래 도움말·관리자·보기 버튼을 같은 줄, 같은 크기로 맞췄습니다.
- 프로파일 만들기의 장비 정보 탭에 벤더·OS 이름을 자유롭게 정해도 된다는 안내를 넣었습니다.
- 장비 점검·연결 진단·프로파일 만들기 도움말과 화면 캡처를 새 화면에 맞게 고쳤습니다.

## 설치 및 주의사항

- 지원 환경은 64비트 Windows 10 버전 1809(빌드 17763) 이상입니다.
- 설치 파일은 `NetOpsSuite-setup-1.3.0.exe`, 설치 없이 쓰는 압축 파일은 `NetOpsSuite-portable-1.3.0.zip`입니다.
- 기본 Program Files 설치 위에 실행하면 이전 실행 파일과 `_internal` 앱 번들이 새 버전으로 교체됩니다. 실행 중인 NetOps Suite를 먼저 종료하세요.
- 저장된 프로파일 파일 형식은 바뀌지 않았습니다. 이전 버전에서 만든 프로파일을 그대로 씁니다.
- 구형 장비용 SSH 구성 요소(Paramiko 3.5.1)는 v1.2.0과 같이 별도 프로세스에서만 사용합니다.
- 코드 서명 인증서가 구성되지 않은 경우 명시적으로 승인된 무서명 릴리스로 게시되며, Windows에서 확인된 게시자 정보가 표시되지 않을 수 있습니다.

## 검증 및 무결성

- 가이드 생성·검증, 정적 검사, 의존성 감사, Python 컴파일과 전체 자동화 테스트를 릴리스 워크플로에서 수행합니다.
- 자동 생성한 추출 규칙이 저장 후 실제 점검에 쓰는 파서에서도 같은 값을 뽑는지, Telnet 로그인이 비밀번호 없는 장비·계정 프롬프트만 있는 장비·로그인 거부에서 맞게 동작하는지 로컬 테스트 서버로 검사합니다. 실제 장비 접속 시험은 포함하지 않습니다.
- 설치 업그레이드 트랜잭션 검사, 패키징된 실행 파일의 시작 검사와 구형 SSH 구성 요소 자체 점검을 통과해야 게시됩니다.
- 설치 파일, 포터블 zip과 함께 `SHA256SUMS.txt` 및 CycloneDX 형식의 `python-dependencies.cdx.json`을 게시합니다. 실제 체크섬과 서명 상태는 게시된 자산과 워크플로 결과에서 확인하세요.
