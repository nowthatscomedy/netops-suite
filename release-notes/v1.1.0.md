# NetOps Suite v1.1.0

`v1.1.0`은 화면 구성과 도움말을 전면 개편하고, 설치 없이 압축만 풀어 쓰는 포터블 실행을 정식으로 지원하는 기능 릴리스입니다. 실험적으로 제공하던 NetOps 어시스턴트(AI) 기능은 제거했으며, SSH 라이브러리를 보안 수정 버전으로 올려 이전 버전의 한시적 취약점 예외를 없앴습니다.

## 한눈에 보기

- 새 `시작` 화면에서 하려는 작업을 고르면 해당 화면으로 바로 이동합니다. 왼쪽 메뉴와 각 작업 화면을 카드 단위로 다시 정리했습니다.
- 화면 오른쪽 위 `도움말` 버튼이나 `F1`로 현재 화면의 단계별 안내를 그림과 함께 열 수 있습니다.
- `장비 점검·백업`에 `사용자 명령` 모드를 추가했습니다. 명령을 직접 입력하거나 파일로 지정하고, Excel 열 값을 `{{ 변수 }}`로 넣어 장비마다 다른 명령을 실행합니다.
- 설치 없이 실행하면 설정·결과·로그가 프로그램 폴더의 `data` 폴더 하나에 저장됩니다. 릴리스에 포터블 zip을 함께 제공합니다.
- 결과 파일은 데이터 폴더의 `results` 아래로 모았습니다. 이전 위치의 결과는 첫 실행 때 자동으로 옮겨집니다.
- NetOps 어시스턴트 화면과 Codex CLI 연동을 제거했습니다.
- Paramiko 5.0과 Netmiko 4.8로 올려 `GHSA-r374-rxx8-8654` 취약점 예외를 제거했습니다.

## 이전 버전과 달라진 점

왼쪽 메뉴 이름과 화면 순서가 바뀌었습니다. `네트워크 설정`은 `내 PC 네트워크`, `CLI 설정 생성`은 `설정 명령 만들기`로 바뀌었고, 파일 전송은 연결 진단에서 분리된 `파일 전송` 화면으로 옮겼습니다. `NetOps 어시스턴트` 메뉴는 더 이상 없습니다. 저장된 AI 관련 설정 항목과 AI 모델 목록 캐시(`config\ai_model_catalog_cache.json`)는 첫 실행 때 정리되며, 사용자 설정·프로파일·결과·로그는 그대로 유지됩니다.

이전 버전은 결과를 `logs\exports`, `inspector\runs`, `config_builder\outputs`에 나눠 저장했습니다. 이번 버전은 데이터 폴더의 `results` 한 곳에 저장하고, 첫 실행 때 기존 결과를 같은 이름의 파일을 덮어쓰지 않고 옮깁니다. 결과 폴더를 직접 지정해 둔 경우에는 그 설정을 유지합니다.

## 새 기능

- `시작` 화면: 현재 주소 확인, 연결 진단, 장비 점검, 명령 파일 작성, 파일 전송 중 필요한 작업을 카드에서 바로 엽니다.
- 현재 화면 도움말: 번호가 붙은 단계, 성공 확인 방법, 안 될 때 할 일을 오른쪽 패널로 보여 주고 전체 도움말로 이어집니다.
- 사용자 명령 모드: 명령 수와 사용 변수를 입력하는 동안 확인하고, `실행 미리보기`로 첫 장비 값이 들어간 실제 명령을 실행 전에 봅니다. `샘플 생성`이 고른 장비 종류와 사용한 변수 열을 넣은 장비 목록 예시를 만듭니다.
- 포터블 실행: `NetOpsSuite-portable-1.1.0.zip`을 원하는 폴더에 풀고 `NetOpsSuite.exe`를 실행합니다. 처음 실행할 때 `data`가 비어 있고 이 PC에 설치본 데이터가 있으면 설정과 사용자 프로파일을 복사해 옵니다.
- 레거시 SSH 호환: 최신 Paramiko가 거부하는 SHA-1 전용 장비는 별도로 준비한 격리 런타임으로 한 번 전환해 접속할 수 있습니다. 설치본에는 이 런타임이 포함되지 않으며 준비 방법은 장비 점검 도움말에 있습니다.

## 개선 및 수정

- 연결 진단, Wi-Fi, 내 PC 네트워크, 설정 명령 만들기, 설정 화면의 입력과 결과 영역을 카드와 접이식 옵션으로 정리하고 아이콘을 통일했습니다.
- 장비 점검의 프로파일 해석, 명령 템플릿 검증, 취소 처리와 모델별 프로파일 선택을 보강했습니다.
- 설정 명령 만들기의 프로파일 작성 대화상자와 장비 값 파일 처리 안정성을 높였습니다.
- 의존성 감사가 예외 없이 통과하도록 `urllib3`와 빌드 도구의 `pip`도 보안 수정 버전으로 올렸습니다.
- 사용자 가이드 전체를 새 화면에 맞게 다시 작성하고 화면 캡처를 갱신했습니다.

## 설치 및 주의사항

- 지원 환경은 64비트 Windows 10 버전 1809(빌드 17763) 이상입니다.
- 설치 파일은 `NetOpsSuite-setup-1.1.0.exe`, 설치 없이 쓰는 압축 파일은 `NetOpsSuite-portable-1.1.0.zip`입니다.
- 기본 Program Files 설치 위에 실행하면 이전 실행 파일과 `_internal` 앱 번들이 새 버전으로 교체되고 이전 런타임 파일은 남지 않습니다. 실행 중인 NetOps Suite를 먼저 종료하세요.
- 포터블 폴더는 쓰기 권한이 있는 위치(예: 문서, 바탕 화면, USB)에 풀어야 합니다. 쓰기 권한이 없으면 `%LOCALAPPDATA%\NetOps Suite`를 대신 사용합니다.
- NetOps 어시스턴트를 쓰던 경우 해당 화면과 설정은 사라집니다. 이전 감사 로그 파일은 삭제하지 않으므로 필요하면 데이터 폴더의 `logs`에서 확인하세요.
- 코드 서명 인증서가 구성되지 않은 경우 명시적으로 승인된 무서명 릴리스로 게시되며, Windows에서 확인된 게시자 정보가 표시되지 않을 수 있습니다.

## 검증 및 무결성

- 가이드 생성·검증, 정적 검사, 의존성 감사, Python 컴파일과 전체 자동화 테스트를 릴리스 워크플로에서 수행합니다.
- 설치 업그레이드 트랜잭션 검사와 패키징된 실행 파일의 시작 검사를 통과해야 게시됩니다.
- 공개 전 Git 히스토리와 작업 트리를 대상으로 비밀정보 검사를 수행합니다.
- 설치 파일, 포터블 zip과 함께 `SHA256SUMS.txt` 및 CycloneDX 형식의 `python-dependencies.cdx.json`을 게시합니다. 실제 체크섬과 서명 상태는 게시된 자산과 워크플로 결과에서 확인하세요.
