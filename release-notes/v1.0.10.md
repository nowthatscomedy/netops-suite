# NetOps Suite v1.0.10

`v1.0.10`은 NetOps 어시스턴트의 지원 범위를 Codex로 명확히 정리하고, 공개 배포 전에 사용자 입력과 프로세스 실행 경계를 강화한 안정성 업데이트입니다. Claude Code와 Gemini 연결 항목을 제거해 실제로 지원하는 인증·채팅 흐름만 화면과 가이드에 남겼으며, 장비 점검 명령 치환과 오프라인 가이드 생성 과정도 더 엄격하게 검증합니다.

## 한눈에 보기

- NetOps 어시스턴트에서 Claude Code와 Gemini 공급자를 제거하고 Codex 전용 연결·채팅 흐름으로 단순화했습니다.
- 장비 점검 프로파일의 사용자 정의 명령 치환 값에 제어 문자와 명령 구분·리디렉션 문자가 들어가지 않도록 차단했습니다.
- 사용자의 대체 실행 동의를 판정하는 조건을 좁혀 부정문이나 질문을 실행 승인으로 잘못 해석하지 않도록 했습니다.
- Windows 프로세스 종료 도구는 변경 가능한 환경 변수 대신 운영체제가 제공하는 시스템 디렉터리에서 찾도록 강화했습니다.
- 사용자 가이드, 화면 캡처와 오프라인 가이드 생성·검증을 실제 화면과 일치하도록 갱신했습니다.

## 이전 버전과 달라진 점

### NetOps 어시스턴트

- 연결 설정과 모델 선택에서 Claude Code 및 Gemini 항목을 제거했습니다.
- 어시스턴트 기능, 상태 문구, 오류 안내와 기능 가이드를 Codex 기준으로 통일했습니다.
- 이미 저장된 예전 공급자 설정이 있더라도 더 이상 지원되는 연결처럼 표시하거나 채팅 경로로 사용하지 않습니다.
- 외부 실행 방식에 대한 동의 문구는 명시적으로 일치하는 승인만 인정합니다. 비슷한 단어가 포함된 부정문이나 단순 문의는 승인을 소비하지 않습니다.

### 장비 점검과 가이드

- Excel 값으로 점검 명령의 변수를 치환할 때 줄 제어 문자와 CLI 구분·리디렉션 문자를 검증합니다.
- 잘못된 치환 값은 장비에 명령을 보내기 전에 중단하고 사용자가 입력을 수정할 수 있는 오류로 안내합니다.
- 연결 설정 및 장비 점검 화면 캡처, 관련 사용자 절차와 문제 해결 설명을 최신 UI에 맞췄습니다.
- 오프라인 가이드 원본은 허용된 로컬 파일만 번들에 포함하며, 링크와 리소스 경계를 빌드·검증 단계에서 확인합니다.

## 새 기능

- 기능 코드와 사용자 가이드의 연결 관계를 검사하는 매니페스트 기반 검증을 추가했습니다.
- 실제 Qt 위젯을 사용하는 오프스크린 캡처 시나리오로 주요 안내 화면과 도움말 흐름을 재현할 수 있습니다.
- Codex가 NetOps 기능을 안내할 때 현재 화면에서 바로 확인할 수 있는 관련 도움말 문맥을 제공합니다.
- 공개 릴리즈 노트의 UTF-8 인코딩, 필수 섹션, 제목과 최소 내용을 자동으로 검사합니다.

## 개선 및 수정

- 프로세스 트리를 종료할 때 실행하는 Windows `taskkill.exe` 경로를 시스템 API로 확인해 환경 변수 변조의 영향을 받지 않게 했습니다.
- 장비 점검 명령 패턴의 치환 값 검사를 강화해 예상하지 않은 추가 명령, 원격 전송 또는 편집 제어 동작으로 이어질 수 있는 입력을 거부합니다.
- 어시스턴트의 대체 실행 동의 상태가 모호한 문장에 의해 해제되거나 실행 승인으로 전달되는 문제를 수정했습니다.
- 가이드 번들 생성 시 심볼릭 링크와 재분석 지점 등 원본 범위를 벗어날 수 있는 파일을 거부하도록 안전 검사를 보강했습니다.
- 가이드 검증, 기능-가이드 동기화 검사와 캡처 증거 검사를 릴리즈 게이트에 포함해 문서와 UI의 불일치를 조기에 발견합니다.
- 제거된 공급자에 연결된 오래된 상태 처리와 모델 목록 경로를 정리해 Codex 로그인 및 채팅 상태가 일관되게 표시됩니다.
- `cryptography` 50.0.0과 `pyOpenSSL` 26.4.0으로 갱신해 공개된 PKCS#7 복호화 취약점 수정 버전을 사용합니다.

## 설치 및 주의사항

- 지원 환경은 64비트 Windows 10 버전 1809(빌드 17763) 이상입니다.
- 제공되는 Windows 설치 파일 이름은 `NetOpsSuite-setup-1.0.10.exe`입니다.
- 기존 설치 위에 설치할 수 있지만, 실행 중인 NetOps Suite를 먼저 종료하고 중요한 사용자 프로파일과 설정은 별도로 백업하는 것을 권장합니다.
- Claude Code와 Gemini는 이번 버전부터 NetOps 어시스턴트 연결 대상으로 제공되지 않습니다. 어시스턴트 기능을 사용하려면 Codex CLI를 설치하고 공식 로그인 절차를 완료해야 합니다.
- 장비 점검 프로파일에서 치환 변수에 명령 구분자나 리디렉션 문자를 의도적으로 사용하던 경우 새 검증에 의해 거부될 수 있으므로, 하나의 안전한 값으로 수정하세요.
- DHCP, 고정 IP, 게이트웨이·DNS 변경과 일부 진단 작업은 Windows 관리자 승인이 필요할 수 있습니다.

## 검증 및 무결성

- 릴리즈 워크플로는 버전 계약, 릴리즈 노트 형식, 자동화 테스트, 정적 검사, Python 컴파일, 오프스크린 UI 시나리오와 패키징 실행 검사를 수행합니다.
- 공개 전 Git 히스토리와 작업 트리를 대상으로 비밀정보 검사를 수행하며, 실패하면 게시 단계로 진행하지 않습니다.
- CI가 정상 완료되면 설치 파일과 함께 `SHA256SUMS.txt` 및 CycloneDX 형식의 `python-dependencies.cdx.json`을 릴리즈 자산으로 게시합니다.
- 코드 서명 자격 증명이 구성된 경우 CI가 설치 파일을 서명하고 검증합니다. 자격 증명이 없거나 검증에 실패한 상태를 성공한 서명으로 표시하지 않습니다.
- 실제 설치 파일의 SHA-256 값과 서명 상태는 GitHub 릴리즈에 게시된 자산과 워크플로 결과에서 확인하세요.
