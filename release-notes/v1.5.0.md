# NetOps Suite v1.5.0

`v1.5.0`은 장비 점검에서 실패한 장비만 다시 실행할 때 결과를 원래 파일에 합치고, SSH 로그인 실패 원인을 더 정확히 알려 주며, 파일 전송의 SCP 받기를 명령줄 `scp`처럼 쓸 수 있게 한 기능 릴리스입니다.

## 한눈에 보기

- `실패한 n대만 다시 실행`이 새 결과 파일을 만들지 않고, 원래 결과 Excel에서 다시 실행한 장비의 행만 새 결과로 바꿉니다.
- SSH 인증 실패를 SSH 방식 문제와 구분해 알려 주고, 장비 목록에 비밀번호가 빠졌으면 그 사실을 함께 알려 줍니다.
- SCP 클라이언트로 `*`, `?` 와일드카드와 폴더를 받을 수 있고, SFTP를 지원하지 않는 장비에서도 기존 SCP 방식으로 받습니다.
- 받지 못한 경로는 결과 표에 장비가 알려 준 이유를 표시하고 나머지 경로는 계속 받습니다.

## 이전 버전과 달라진 점

v1.4.0에서는 실패한 장비만 다시 실행하면 결과 Excel, 백업 폴더, 세션 로그 폴더가 새 실행 시각으로 따로 생겼습니다. 이제 원래 실행 시각을 그대로 써서 같은 결과 Excel의 해당 장비 행만 바꾸고, 다시 실행한 장비의 백업 파일과 세션 로그도 원래 폴더에 덮어씁니다. 나머지 장비의 행과 순서는 그대로입니다. 점검, 백업, 점검+백업, 명령 일괄 입력에 모두 적용됩니다.

SCP 클라이언트는 이전에도 SCP 프로토콜을 썼지만, 받을 경로에 와일드카드나 폴더를 쓸 수 없었고 경로 하나가 실패하면 원인이 잘 보이지 않았습니다. 이제 명령줄 `scp -O -P 포트 계정@장비:경로 ./`와 같은 방식으로 받습니다.

## 새 기능

- 실패 장비 재실행 결과 합치기: 화면 요약에 `다시 실행한 n대의 결과를 원래 결과 Excel에 합쳤습니다.`가 함께 나옵니다.
- SCP 받기 와일드카드·폴더: `/tmp/rotate/*.tar.gz`처럼 여러 파일을 한 번에 받고, 폴더는 하위 폴더까지 같은 구조로 받습니다.

## 개선 및 수정

- SSH 인증 실패 안내: 구형 장비 호환 모드로 접속한 장비에서 계정이 틀린 경우에도 SSH 방식 오류가 아닌 인증 실패로 알려 줍니다. 장비 목록의 password 칸이 비어 있으면 안내 끝에 그 내용을 붙입니다.
- SCP·SFTP 오류 안내: 응답이 없거나 거부되면 포트가 장비 SSH 포트와 같은지 먼저 확인하라고 알려 주고, SFTP를 열어 주지 않는 장비는 SCP로 받으라고 안내합니다.
- SCP 포트 칸을 비우면 22를 씁니다.
- 장비 점검과 파일 전송 도움말을 새 동작에 맞게 고쳤습니다.

## 설치 및 주의사항

- 지원 환경은 64비트 Windows 10 버전 1809(빌드 17763) 이상입니다.
- 설치 파일은 `NetOpsSuite-setup-1.5.0.exe`, 설치 없이 쓰는 압축 파일은 `NetOpsSuite-portable-1.5.0.zip`입니다.
- 기본 Program Files 설치 위에 실행하면 이전 실행 파일과 `_internal` 앱 번들이 새 버전으로 교체됩니다. 실행 중인 NetOps Suite를 먼저 종료하세요.
- 실패한 장비만 다시 실행하면 원래 결과 Excel이 바뀝니다. 처음 결과를 따로 남기려면 다시 실행하기 전에 파일을 복사해 두세요.
- 저장된 프로파일 파일과 장비 목록 Excel 형식은 바뀌지 않았습니다.
- 코드 서명 인증서가 구성되지 않은 경우 명시적으로 승인된 무서명 릴리스로 게시되며, Windows에서 확인된 게시자 정보가 표시되지 않을 수 있습니다.

## 검증 및 무결성

- 가이드 생성·검증, 정적 검사, 의존성 감사, Python 컴파일과 전체 자동화 테스트를 릴리스 워크플로에서 수행합니다.
- 재실행 결과가 같은 결과 Excel에 합쳐지는지, SSH 인증 실패 구분, SCP 와일드카드·폴더 받기와 경로별 오류 표시를 자동화 테스트로 검사합니다. 실제 장비 접속 시험은 포함하지 않습니다.
- 설치 파일, 포터블 zip과 함께 `SHA256SUMS.txt` 및 CycloneDX 형식의 `python-dependencies.cdx.json`을 게시합니다. 실제 체크섬과 서명 상태는 게시된 자산과 워크플로 결과에서 확인하세요.
